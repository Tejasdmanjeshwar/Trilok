# C3.5 — Human facial topology and semantic control foundation

**Status:** Implementation on feature branch; acceptance pending owner review and full anatomical acceptance. The source-compatible contour-edge implementation has automated verification but is not finished facial anatomy. This is *not* a completed expressive face rig or production art asset. C3.6, C4 and C7 are out of scope.

## Source audit and existing limitations

- Pinned C2 MakeHuman CC0 **body** topology is a single closed indexed skinned source. The importer duplicates UV corners but retains immutable original source vertex IDs; facial material, seam and skin provenance must survive shape/reconstruction. See [C2 import](character-studio-c2-anatomical-import.md).
- C1 has a head and jaw joint, but *not* independent eyelid, lip, nose, cheek, or ear joints. C3.4 has two orbital surface probes and broad head-region deformation, not a dense expression rig.
- Existing C3.4 morphs preserve the source face indices, so small facial areas have only source-provided resolution. Head/jaw influences are inherited from official C2 weights and remain imperfect near thin oral/eyelid regions. The mesh does **not** have guaranteed eyelid rings, inner mouth cavity, individual nostril rims, eye sockets ready for anatomical eye animation, or lip mucosa. Artificially adding vertex density cannot create these missing anatomical structures.
- Previously merged primate/bear shared-topology previews remain **unaccepted experimental legacy**. Rejected PR #52 was not merged; its licensed face atlas is not used here.

## Implemented API

`FacialTopology.ts` exports a stable `FACIAL_TOPOLOGY_VERSION=1`, a 26-region `FACIAL_REGION_IDS` registry, source vertex/bone role landmarks, radial local authoring fields and `inspectHumanFacialTopology(human)`. The atlas derives eye, chin, crown and neck references from *owned neutral C2/C3.4 geometry* and C1 head/jaw weights. It includes orbital corners, upper/lower eyelids, brows, nasal bridge/tip, paired nostrils, lips, mouth corners, cheeks, jaw, chin and ears. The fields are a C3.6-compatible **control foundation**; they do not yet implement expressions or facial animation and they are not additional bones.

`refineHumanFacialTopology(human,{maxSourceEdges,minimumEdgeLengthMeters})` performs one conforming, adaptive pass on front-facing candidate source edges near those semantic fields. Canonical source-edge selection ensures both UV copies split together; face winding and original indices are preserved as a prefix of the new attribute buffers. Each new midpoint receives interpolated UV, normalized four-influence skinning and a stable two-source-vertex edge descriptor (not a fictitious upstream source vertex ID). Limits: 1–3000 split source edges, default 1200, minimum length default 2.5 mm. Refinement can only be performed once on the owned source geometry, after neutral rest-space C3 shaping and inverse-bind recalibration. It never mutates the canonical source template's original buffers. An explicit disposal path releases both original and derived GPU geometries.

The refined human lab pipeline now composes that source-compatible pre-pass with `buildHumanFacialEdgeFlow` (`FacialEdgeFlow.ts`), a deterministic conforming iso-contour insertion stage. Source-derived feature anchors establish paired elliptical orbit, brow and nostril bands and central oral/nasal bands; 22 authored contour levels are subdivided directly **into the one existing continuous skinned surface**, including every duplicated UV corner. Each interior contour uses closed mesh-edge adjacency, immutable stable topology IDs, exact interpolated UVs and bounded four-bone weights. Splits are kept at least eight percent along edges to avoid near-zero-area triangles discovered in an initial CI regression. New C3.5 tests reject disconnected rings, malformed triangles, invalid skin weights, non-deterministic ancestry and non-recovering jaw poses. All curved bands are diagnostic topology scaffolding, **not anatomically certified eyelid rims, eyelid closure, nostril apertures or an open mouth**.

The opt-in **C3.5 feature-aligned human facial edge flow** checkbox in Character Lab can compare source and refined human rendering and wireframes. The status panel provides actual vertex, triangle, and selected edge counts. Lab controls preserve camera orbit while rebuilding. Default original source and all combat behavior remain untouched.

## Measured pinned-source facial density and visual evidence (2026-11-13)

Actual Fast Verify #43466330146 (55 passing Vitest files, typecheck, production build and build identity) measured **14,517 render vertices**, **26,756 triangles** and **19,158 original MakeHuman OBJ source vertex records**, with zero open or non-manifold edges on the imported body source. The unrefined original face has very sparse localized zones: **4 upper-lid control samples per eye**, **13 lower-lid samples per eye**, **6 brow samples per side**, **3 inner-eye corner samples per side**, **9 nose-tip samples**, **14 nostril samples per side**, **23 upper-lip and 18 lower-lip samples**, **8 mouth-corner samples per side**. Region coverage uses a normalized local influence threshold and is not equivalent to anatomical edge-loop count. This is **not sufficient evidence of high-detail eyelid/lip deformation**.

C3.5 Chromium visual run [#43466330263](https://github.com/Tejasdmanjeshwar/Trilok/actions/runs/43466330263) passed desktop and touch. Its 10 artifact screenshots include front, side, three-quarter, jaw-open and wireframe on both modes. The rendered face remains visibly the existing human source; no missing functional anatomical loops were invented. Neck/body continuity holds in the sample views, and the original C1 jaw pose still opens, but this does not certify absence of contact artifacts or visual realism.

**C3.5 acceptance caveat:** the new connected elliptical edge bands improve *topological control*, but do not remove the underlying anatomical blocker. Continuous contour lines on closed source skin cannot create an open mouth, mobile eyelid rims or true nostril apertures. Those would require an anatomically justified, source-compatible remeshing/retopology pass with authored feature boundaries, bilateral control validation and final deformation/rendered acceptance. A closed contour graph does **not** certify biologically correct edge flow. The current implementation remains a **draft/partial foundation** until those necessities and visual acceptance are resolved.

## C3.5 bounded facial aperture study (draft; 2026-11-13)

`FacialApertures.ts` now implements an **independent, diagnostic only**, source-connected topology study for two orbital regions, two nostril regions and one oral region. Each feature is cut from the existing C2 / C3.5 skinned surface by selecting a validated canonical edge loop, removing its enclosed source-disk triangles, and stitching two inward-oriented rings plus a recessed cap. The exterior mesh and cavity share boundary edges; no detached primitive or new skeleton bone is introduced. The surfaces are **closed, capped recesses**: not anatomically open airways, eyeballs, a functional eyelid aperture, a deep mouth cavity, lips with inner mucosa, or character-expression morph targets.

The opt-in **C3.5 recessed eyes, nares and mouth boundary study** lab checkbox selects this research variant independently of the source/head contour-only view; it is disabled outside human CC0 geometry. It is not used by combat or the accepted human base. The source vertex array and UV prefix remain unchanged (interior vertices may become intentionally unreferenced after excision); original source normals are retained for those old unused vertex records while generated vertices must be valid and owned.

**Measured CI result:** [Fast Verify #43477408180](https://github.com/Tejasdmanjeshwar/Trilok/actions/runs/43477408180) passed TypeScript, **295 tests in 56 files**, production build and generated build identity. The neutral capped recess study yielded **17,726 render vertices / 32,976 triangles** on the *whole human body*, versus 14,517 / 26,756 in the original C2 body. Five feature pockets, 0 topology boundary edges, 0 nonmanifold edges and normalized four-influence weights were recorded. The tests additionally check deterministic rebuild, original source-prefix immutability, C3.4 head-shape compatibility, existing jaw FK and resource disposal. These are topological and technical checks, **not proof of anatomical credibility, eye closure, lip movement or mouth interior function**.

A second gate uses desktop/touch Playwright to capture front/profile, wireframe and jaw-open diagnostics. Visual owner acceptance, deformation stress validation for the new recess rims, representative mobile performance, and proof of biologically credible openings remain **outstanding**. Do not merge the draft PR until those gates are addressed or the owner explicitly accepts a narrower topology-only C3.5 contract.

## Acceptance and limitations

Vitest should exercise deterministic atlas ordering, bilateral field separation, source skin ownership, canonical edge continuity, UV/geometry preservation, four-weight normalization, C1 head/jaw FK and neutral recovery, budget validation, reproducible generation and idempotent disposal. Verify TypeScript, full Vitest + combat replay, build identity and both Chromium modes in CI. Capture and review **front, three-quarter, profile, jaw open/closed and close wireframe** rendered views on the feature-branch build. Require owner approval before merge.

**Not claimed:** measured final density adequacy around each eyelid and lip contour, reconstructed anatomical edge loops, production-ready nostril/mouth cavities, stress-free extreme deformation, GPU profiling on low-end phones, or visual sign-off. The existing upstream mesh may ultimately require a separately licensed higher-fidelity human face template with validated source-to-C2 bridging; such a replacement requires a new explicit asset-provenance and rigging review, not undocumented hardcoding.
