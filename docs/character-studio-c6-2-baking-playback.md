## Current implementation

- The optional offline `scripts/extract-quaternius-ual1.mjs` reads only the three chosen GLB glTF animation channel sets and the source rest hierarchy. Its curated JSON sits under `assets/animations/sources/`. The source GLB and archive are not shipped in the runtime.
- `scripts/bake-reference-animations.mjs` deterministically derives canonical `AnimationClipV1` local rest-delta quaternion tracks using source world-rest orientation differences, target parent hierarchy and identity of source vs canonical left/right conventions. The generated assets and SHA-256 manifest are under `assets/animations/reference-v1/`.
- `pnpm animation:verify` checks regenerated bytes exactly against the committed artifacts. The source filename, source and archive hashes, importer and retargeter revisions, and derived artifact hashes are recorded in `manifest.json`.
- `StudioAnimationPlayback` now uses `StudioPosePreview.applyAnimationSamples`, which routes samples through the established `AnatomicalFK.applyRestDeltas` on the existing calibrated MakeHuman bones. The same method synchronizes the separately weighted shoulder connector and proximal non-twisting forearm skin helper; `HumanPoseCorrectives` controls existing shoulder/hip morphs.
- Root motion remains a **presentation-only** offset. Idle is locked (no root translation track); walk/run preserve small lateral/vertical source pelvis motion without forward world displacement. The world-position authority remains untouched.
- Static C5 pose/equipment restoration remains the existing Studio lifecycle. Gameplay combat/AI/projectile authority remains unchanged.

### Important quality and compatibility caveats

This is a first-pass rest-aware transfer, **not a proven visually acceptable retarget**. The canonical target rest directions and the actual CC0 mesh bind orientations require real rendered checks across morphologies. The extra C1 `foot` joint and missing Quaternius anatomical helpers are mapped conservatively; no C6.3 planting/IK/grounding solver is included. The C3 correctives remain approximate by design and must be inspected against actual shoulder/hip deformation. No animation is certified natural, polished or AAA solely from passing these tests.
